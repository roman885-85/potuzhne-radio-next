# ПОТУЖНЕ РАДІО (Nextion)

Інтернет-радіо **ПОТУЖНЕ РАДІО** для іншого заліза: ESP32 (класичний, 4 МБ), апаратний декодер
**VS1053**, картка пам'яті й сенсорний екран **Nextion NX4832F035** (3,5″, 480×320). Старший брат —
[ПОТУЖНЕ РАДІО на ES3C28P](https://github.com/roman885-85/potuzhne-radio).

> Проєкт у роботі. Нижче — що вже є і що буде.

## Що буде

- Радіостанції з інтернету й музика з картки; керування з екрана, кнопкою, з браузера й програмами ПОТУЖНОГО РАДІО.
- **Весь інтерфейс живе в самому екрані Nextion**: сторінки, шрифти, значки, написи українською. ESP32 лише
  надсилає дані й отримує натискання — прошивка вільна від графіки.
- **Bluetooth-колонка**: окремий режим, на радіо можна передати звук із телефона (A2DP).
- **Оновлення з цього репозиторію**: радіо саме знаходить новий випуск і оновлює і прошивку, і екран.

## Залізо й виводи

| Що | Виводи ESP32 |
|---|---|
| Nextion NX4832F035_011 | RX 14 (← TX екрана), TX 13 (→ RX екрана), 5 В |
| VS1053 (VSPI 18/19/23) | CS 32, DCS 33, DREQ 34, RST 12 |
| Картка пам'яті (та сама VSPI) | CS 25 |
| Кнопка «режим» | 36 (вхід без внутрішньої підтяжки — резистор на платі) |
| Пробудження | 39 |
| Вимкнення звуку (MUTE) | 22 |
| Світлодіод | 4 |

## Розмітка пам'яті (4 МБ)

| Розділ | Адреса | Розмір | Що там |
|---|---|---|---|
| nvs | 0x9000 | 20 КБ | налаштування |
| otadata | 0xE000 | 8 КБ | яку програму запускати |
| factory | 0x10000 | 1,06 МБ | оновлювач: завантажує з GitHub прошивку, файли сторінки й екран |
| app0 | 0x120000 | 2,75 МБ | основна прошивка: радіо + Bluetooth |
| spiffs | 0x3D0000 | 128 КБ | сторінка радіо, станції, мережі |
| coredump | 0x3F0000 | 64 КБ | звіт про збій |

Чому не звичні два розділи по 1,9 МБ: із Bluetooth-колонкою прошивка важить ~2 МБ і туди не вміщається.

## Збирання

```bash
firmware/rebuild.sh
```

Власна копія ядра arduino-esp32 **2.0.17** ставиться в `build/arduino15` (на 3.x із Bluetooth не
вистачає IRAM). Бібліотека Bluetooth — [ESP32-A2DP](https://github.com/pschatzmann/ESP32-A2DP).
